# Электронная лётная книжка пилота

Курсовой проект: учёт полётов, автоматический расчёт налёта, роли **пилот** и **начальник авиакомпании**.

## Возможности

### Пилот
- Регистрация и вход
- Ведение своей лётной книжки (CRUD)
- Выбор **самолёта** и **маршрута** из списков
- Автоматический расчёт налёта по времени взлёта и посадки
- Статистика за период (общий налёт и по типам ВС)
- Редактирование профиля и смена пароля

### Начальник авиакомпании
- Просмотр всех пилотов и их общего налёта
- Карточка пилота: контакты, удостоверение, статус
- Просмотр и редактирование полётов любого пилота
- Добавление пилотов, изменение данных, сброс пароля, блокировка

## Запуск через Docker

```bash
cd pilot-logbook
docker compose down -v   # при обновлении схемы БД
docker compose up --build
```

Откройте: **http://localhost:8082/** (перенаправит на вход)

## Локальный запуск

1. Применить `src/main/resources/sql/init.sql` к MySQL
2. Настроить `application.properties`
3. `mvn spring-boot:run` в каталоге `pilot-logbook`

## Тесты

```bash
mvn test
```

## Стек

Spring Boot 3, Spring Security, JPA, Thymeleaf, Bootstrap 5, шрифт Onest (кириллица), MySQL.
